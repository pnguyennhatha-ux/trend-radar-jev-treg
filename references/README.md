# Your photos

Drop 1 to 4 photos of yourself here for thumbnails. Face clear and big, looking at the camera, plain background.

- The first file by name is the main face. Name it `01-face.jpg`.
- Add a smile and a point or wave if you have them: `02-smile.jpg`, `03-point.jpg`.
- JPG or PNG. Upright. No photo means thumbnails show a generic person.
